# Tikai

**Ti**c**k**ets + **AI** -> **Tikai**

Ticket + AI + Developing + Reviewing

## Goal & Motivation
The goal of this project is to develop software projects with the help of AI (especially with multiple AI - Agents) while keeping the reviewing and controlling for humans simple.

The most important things are:
- good planning- and ticket- system
- versioning
- multiple agents in sandboxes
- every step & change is documented & traceable
(see more in [Why Tikai](docs/why-tikai.md))
